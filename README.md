# 青聊

类似微信的响应式网页版通讯界面。本版本是本地交互原型，联系人和初始消息为演示数据，不会向其他用户发送消息。

## 启动

```sh
cd /workspace/wechat-web
python3 -m http.server 3000 --bind 0.0.0.0
```

访问 http://localhost:3000 。远程工作环境需通过环境的端口转发访问 3000。

## 功能

会话及通讯录、搜索、文字发送、表情、图片（最大 1 MB）、添加本地联系人、手机布局。消息保存在当前浏览器的 localStorage，清除浏览器数据后会丢失。图片也占用浏览器存储配额。

## 后续

真正的多人通讯需要增加账号认证、服务端数据库、实时消息通道、成员权限和文件存储。本版本没有实现这些功能，也没有语音视频通话。

## 验证

JavaScript 语法检查和静态 HTTP 资源访问检查通过。环境未提供浏览器预览工具，未进行浏览器交互验证。
